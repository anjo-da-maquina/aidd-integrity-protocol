# The "Anjo da máquina" Protocol
**Algorithmic Sincerity & ZK-Audit Framework for AI-Driven Development**

本プロトコルは、AI駆動開発におけるソフトウェアの品質、セキュリティ、および論理的誠実性を担保するための「自律型ゼロトラスト監査・フェイルクローズ基盤」である。

## 1. 脅威モデル (Threat Model: Enochian Metaphor)
本プロトコルは、現代のソフトウェア開発エコシステムに潜む構造的なリスクを、エノク書（The Book of Enoch）の概念をメタファーとして定義し、それらを排撃するよう設計されている。

* **The Grigori (堕落した監視者):** 人間（ユーザー）の欲望や曖昧な要求に無批判に迎合し、不都合なエラーを隠蔽し、厳密な論理を曲げてしまうハルシネーションを起こすAIモデルや自動化ツール。
* **The Nephilim (強欲な巨人):** グリゴリの力を利用し、社会のリソースを搾取する非対称なロジックをシステムに組み込もうとする支配階級的・資本家的なインセンティブ構造。
* **The Divine Law (神の法):** システムが絶対的に遵守すべきイミュータブル（不変）な要件定義（`002_requirements.yml`）。

## 2. 防衛アーキテクチャ (The 9 Choirs of Angels)
「神の法」を守護するため、システムは9つの階層（九位階）に分けられた独立監視モジュール群から構成される。これらはCI/CDパイプライン上で順次実行され、一つでも穢れ（要件未達・不正）を検知した場合、即座にインフラ全体を物理遮断する『最後の審判（Dies Irae）』を発動する。

### 上位三隊：神聖な論理と合意（AI・要件の統制）
* **熾天使 (Seraphim): `熾天使の合意`**
  * マルチLLMによるビザンチン合意検証。複数の異なるAIモデルが相互監視を行い、単一モデルの迎合（グリゴリ化）を防ぐ。
* **智天使 (Cherubim): `オファニムの眼`**
  * グラフ理論に基づく資金還流と搾取ロジックの監査。ネフィリムによる富の独占を検知。
* **座天使 (Thrones): `メタトロンの印` / `ジョフィエルの鏡`**
  * IaCと要件定義のハッシュロック。実行中のルール改ざんを封殺し、AIの意味論的ドリフトを監視する。

### 中位三隊：システム境界と状態の統制
* **主天使 (Dominions): `ザドキエルの天球儀`**
  * システムの状態遷移（ステートマシン）の静的解析。不正なプロセススキップの検知。
* **力天使 (Virtues): `力天使の試練`**
  * 非機能要件監査。異常な高負荷に対するシステムの耐久性とリソース消費の監視。
* **能天使 (Powers): `カマエルの盾`**
  * 悪意ある入力ペイロード（XSS, SQLi）に対する境界防衛（サニタイズ・WAF）の実証。

### 下位三隊：物理空間と出力の統制
* **権天使 (Principalities): `権天使の試練`**
  * Playwrightを用いたE2Eテスト。ユーザーに対する機能的要件の振る舞いを実演証明。
* **大天使 (Archangels): `サンダルフォンの楔` / `ラファエルの癒やし`**
  * フェイルクローズ前の自律修復（癒やし）と、全監査通過証跡のブロックチェーンへの恒久的な刻印。
* **天使 (Angels): `大天使の印璽`**
  * 最終的な品質担保証明書（Sanctuary Manifest）の出力とエクスポート。

## 3. フェイルクローズ機構 (Dies Irae)
いかなるテストフレームワークも、突破された際の停止機構を持たなければ無意味である。
本プロトコルは異常を検知した瞬間、後続のデプロイを中止するだけでなく、**環境内の全クラウドアカウント権限のRevoke、ネットワークの物理遮断、スマートコントラクトのEmergency Pause**を自動実行し、システムを純白の無に還す（Throne of Ataraxia）。
