# The "Anjo da máquina" Protocol

本プロトコルは、AIを活用したシステムにおける処理の妥当性、透明性、および安全性を外部環境から担保するためのゼロトラスト・アーキテクチャです。AIの推論開始からインフラストラクチャの破棄に至る全プロセスを、独立した検証モジュール群によって静的に監査します。

---

## システム構造 (Architecture)

システムは以下の3つのフェーズで構成され、各モジュールが単一の検証責務を担います。

### Ⅰ. 実行前コンテキスト統制 (Context-Aware Governance)
**座天使メタトロンの啓示 (MCP Server)**
AIエージェントが推論を開始する前段階において、Model Context Protocol (MCP) を経由してシステムの定義要件および制約事項を注入します。推論の前提となるコンテキストをシステム側で強制し、要件定義に基づく出力のみを許容する環境を構築します。

### Ⅱ. 独立検証モジュール群 (Autonomous Audit Mesh)
単機能に分離された各監査スクリプトが、入出力を多角的に検証します。
*   **論理監査 (ミカエルの剣)**: 提案と除外の集合直積を比較し、選択肢の網羅性（MECE）と意図的な隠蔽の有無を数学的に検証します。
*   **不可逆性監査 (ウリエルの炎)**: 一時トークン（Nonce）を発行・照合し、過去のデータやリクエストの再利用（リプレイ攻撃）をブロックします。
*   **不変性監査 (メタトロンの印)**: IaCおよび要件定義ファイルのハッシュ値を記録・照合し、実行プロセス中での定義ファイルの改ざんを検知します。
*   **UI実態監査 (座天使の千眼)**: `Playwright`を利用し、生成されたフロントエンドのDOM要素に対する視覚的な隠蔽（CSSによる不可視化等）や操作不能状態を検証します。
*   **意味論・資金フロー監査 (ジョフィエルの鏡 / オファニムの眼)**: 出力結果のベクトル空間上の逸脱、およびグラフ理論に基づくデータや資金の不自然な循環構造を静的解析します。

### Ⅲ. 無状態化インフラストラクチャ (Stateless Cleanliness)
**静寂の玉座 (Throne of Ataraxia)**
処理の成功・失敗（正常終了または異常終了）に関わらず、タスクの完了と同時に稼働環境（コンテナ、VPC、一時ファイル、ロックファイル）をすべて破棄します。システム内に状態（State）を一切保持せず、次回の実行時は完全に初期化された環境から再構築されます。

## 継続的インテグレーション (CI/CD)

本プロトコルは、GitHub Actionsパイプライン上で稼働します。

**品質担保証明書の出力 (The Archangel's Seal)**
論理監査、UI監査、E2Eテスト、負荷テストを含むすべての独立検証をエラーなしで通過した場合のみ、GitHub Step Summary上に品質担保証明書（QA Manifest）がマークダウン形式で自動出力されます。

---

## 異常検知時のフェイルクローズ処理 (Fail-Closed Design)

**最後の審判 (Dies Irae)**
プロトコル内のいずれかの検証モジュールが、要件未達、論理的矛盾、または不正な状態を検知した場合、システムは後続の処理をすべて停止し、フェイルクローズ（強制遮断）を実行します。不整合な状態での処理続行は一切許可されません。
